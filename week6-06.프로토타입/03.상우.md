## 1. 객체 전용 메서드의 예외사항

### 🚨 문제 제기: Object.prototype은 만물의 근원

자바스크립트의 모든 데이터(배열, 함수, 숫자 등)는 프로토타입 체인을 타고 올라가면 무조건 최상단의 `Object.prototype`을 만나게 됩니다. 즉, 오직 '순수 객체'만을 위해서 만든 메서드를 `Object.prototype` 영역에 선언해 버리면, 배열이나 함수 등 모든 데이터 타입이 그 메서드를 공유하고 마음대로 호출할 수 있게 되는 대참사가 발생합니다.

### 💡 해결책: 스태틱(Static) 메서드 부여

이러한 문제를 방지하기 위해 자바스크립트는 객체만을 위한 메서드들을 `prototype` 안에 넣지 않고, **`Object` 생성자 함수 자체에 '스태틱(Static) 메서드'로 직접 부여**했습니다.

- **this 사용 불가:** 체인에 없기 때문에 `obj.keys()`처럼 인스턴스 자신의 `this`를 활용해 호출할 수 없습니다.
    
- **직접 주입 방식:** 대신 `Object.keys(obj)`처럼 대상 인스턴스를 인자로 직접 주입해야 하는 방식으로 구현되어 있습니다.
    

> **❓ 질문: `Object.freeze()`는 무엇인가요?** 대표적인 객체 전용 스태틱 메서드 중 하나입니다. 객체를 **'동결'**시켜서 새로운 속성을 추가하거나 기존 속성을 삭제/수정하지 못하게 막아버리는(완전한 불변 객체로 만드는) 역할을 합니다. _사용 예:_ `Object.freeze(obj);`

### 🛡️ 예외 케이스: Object.create(null)

모든 객체가 `Object.prototype`을 상속받는 것은 아닙니다. 예외적으로 `Object.create(null)`을 이용해 객체를 생성하면, `__proto__`가 없는(즉, 부모가 없는) 완전한 빈 객체가 만들어집니다. 이 객체는 내장 메서드(`hasOwnProperty` 등)에 접근할 수 없는 진짜 순수 데이터 사전(Dictionary) 용도로 쓰입니다.

## 2. 다중 프로토타입 체인

자바스크립트에서는 기본적으로 연결된 프로토타입 체인 외에도, 사용자가 대각선으로 `__proto__`를 더 연결하여 **다중 프로토타입 체인**을 만들 수 있습니다.

- **연결 방법:** 하위 생성자 함수의 `prototype` 객체가 **연결하고자 하는 상위 생성자 함수의 '인스턴스'를 바라보게끔** 할당해주면 됩니다.
    
- **효과:** 이 방법을 사용하면 객체(예: 유사 배열 객체)가 마치 진짜 배열인 것처럼 `push`, `pop` 같은 배열의 메서드를 체인을 통해 가져다 쓸 수 있게 됩니다.


```js
// 발표용 간단한 코드 예시
var Grade = function() {
  var args = Array.prototype.slice.call(arguments);
  for (var i = 0; i < args.length; i++) {
    this[i] = args[i];
  }
  this.length = args.length;
};

// 🌟 다중 프로토타입 체인 연결의 핵심!
// Grade의 인스턴스가 배열의 메서드를 쓸 수 있도록 Array의 인스턴스를 prototype에 할당
Grade.prototype = []; 

var g = new Grade(100, 80);
g.push(90); // 원래는 객체라서 push를 못 쓰지만, 체인 덕분에 가능해짐!
console.log(g); // Grade(3) [100, 80, 90]
```

## 3. 6장 전체 요약 (정리)

프로토타입 챕터의 가장 중요한 핵심 원리들을 요약합니다.

- **생성자 함수와 프로토타입:** 모든 생성자 함수는 `prototype` 이라는 유산 창고 객체를 가지고 있습니다.
    
- **`new`와 인스턴스화:** `new` 키워드로 인스턴스를 만들면, 인스턴스 내부에는 `__proto__`라는 프로퍼티가 생기며 이는 생성자 함수의 `prototype`을 참조합니다.
    
- **`__proto__`의 생략과 체이닝:** `__proto__`는 생략 가능한 속성입니다. 따라서 `인스턴스.__proto__.메서드()`가 아니라 `인스턴스.메서드()`로 호출해도, 엔진이 알아서 프로토타입 체인을 타고 부모의 메서드를 찾아 실행합니다. (이때 `this`는 인스턴스 자신을 유지합니다.)
    
- **`constructor` 프로퍼티:** `prototype` 객체 안에는 `constructor`라는 명찰이 있으며, 이는 자신을 만든 '생성자 함수 본체'를 다시 가리킵니다.
    
- **궁극의 조물주 (Object와 Function):**
    
    - 그냥 함수를 선언하는 순간, 내장된 `Function` 생성자 함수의 프로토타입을 상속받아 만들어집니다.
        
    - 그 `Function.prototype` 역시 객체이므로, 결국 `Object.prototype`을 상속받습니다.
        
    - **체인의 끝:** `__proto__` 방향을 계속 찾아 올라가면 최종적으로 맨 상위에는 `Object.prototype`이 존재합니다. 더 이상 올라갈 곳이 없으므로 **`Object.prototype.__proto__`에는 `null`이 박혀 있습니다.** (여기서 체인이 종료됩니다.)
