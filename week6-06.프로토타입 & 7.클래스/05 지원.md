# 07 클래스

### 03 클래스 상속

---

#### 7-3-1 기본 구현

과거(ES5 시절까지)에 프로토타입 체인을 활용해 클래스 상속을 흉내내기 위해 했던 방법들.

ES6에서 `class` 문법이 등장했지만, 내부적으로는 여전히 `prototype` 기반이다. 따라서 여전히 프로토타입 체인의 연결을 이해하는 것이 중요!

---

```jsx
var Grade = function () {
  var args = Array.prototype.slice.call(arguments);

  for (var i = 0; i < args.length; i++) {
    this[i] = args[i];
  }

  this.length = args.length;
};

Grade.prototype = [];

var g = new Grade(100, 80);
```

![image.png](6%EC%A3%BC%EC%B0%A8/image.png)

→ 이런 프로토타입 체인이 생성되고, g는 push 와 같은 배열의 메서드를 사용 가능해짐.

#### length 삭제 예제

```jsx
g.push(90);
// Grade { 0: 100, 1: 80, 2: 90, length: 3 }

delete g.length;
g.push(70);
// Grade { 0: 70, 1: 80, 2: 90, length: 1 }
```

→ g.length가 삭제된 후 JS엔진은 g → g.__**proto__** → Array.prototype 순서로 length를 찾는데, g.__proto__.length가 0이기 때문에 인덱스 0자리에 70을 push 하게 된 것. 

```jsx
Grade prototype = ['a', 'b', 'c', 'd'];

g.push(90);
// Grade { 0: 100, 1: 80, 2: 90, length: 3 }

delete g.length;
g.push(70);
// Grade { 0: 100, 1: 80, 2: 90, __ 4: length: length: 5}
```

→ 똑같이 g의 length가 없으니 g.__proto__.length를 찾았는데 길이가 4라서 인덱스 4에 70을 넣은 것.

클래스 역할을 하는 prototype 객체가 실제 데이터나 상태(state)를 가지면 그 값이 인스턴스 동작에 영향을 주게 된다. 프로토타입은 **메서드만 가져야 하고 구체적인 데이터는 가지면 안 된다**.

---

#### Rectangle / Square 상속 예제

```jsx
var Rectangle = function (width, height) {
  this.width = width;
  this.height = height;
};
Rectangle.prototype.getArea = function () {
  return this.width * this.height;
};

var Square = function (width) {
	this width = width;
}:
Square.prototype.getArea = function () {
	return this.width * this.width; 
};
```

Rectangle과 Square 클래스에 공통 요소가 보여 Ractangle을 상속하는 Square로 변경

```jsx
var Square = function (width) {
  Rectangle.call(this, width, width);
};

Square.prototype = new Rectangle();
```

생성자 함수 `Rectangle.call(this, width, width);` 를 호출함으로 현재 객체(this)에 속성 복사하여 상속을 실행하게 된다. 

**sq → Square.prototype → Rectangle.prototype → Object.prototype** 으로 프로토타입 체인이 연결된다.

#### 7-3-2 클래스가 구체적인 데이터를 지나지 않게 하는 방법

#### 1. 프로퍼티 제거 + freeze

```jsx
delete Square.prototype.width;
delete Square.prototype.height;

Object.freeze(Square.prototype);
```

- prototype 에 실제 데이터 제거
- 메서드만 남기기
- 새로운 값 추가 방지

---

#### 2. Bridge 패턴

직접 `new Rectangle()`을 prototype 에 넣지 말고, 중간 빈 함수(Bridge)를 사용.

```jsx
var Bridge = function () {};
Bridge.prototype = Rectangle.prototype;
Square.prototype = new Bridge();
```

![image.png](6%EC%A3%BC%EC%B0%A8/image%202.png)

sq → Square.prototype → Bridge.prototype → Rectangle.prototype → Object.prototype 로 중간에 빈생성자 함수를 끼워 넣음으로 prototype 에 실제 데이터 없고, 메서드만 상속 가능하도록 함.

---

#### 3. Object.create()

```jsx
Square.prototype = Object.create(Rectangle.prototype);
Object. freeze(Square.prototype);
```

SubCLass의 prototype 의 __proto__가 Superclass의 prototype을 바라보되, Superclass 의 인스턴스
가 되지는 않으므로 앞서 소개한 두 방법보다 간단하면서 안전하다.
