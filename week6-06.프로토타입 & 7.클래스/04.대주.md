# 자바스크립트와 클래스

## 내용 정리

자바스크립트는 원래 **프로토타입 기반 언어인데** 많은 개발자들이 클래스 기반 언어에 익숙했기 때문에 자바스크립트에서도 클래스처럼 동작하게 만드는 여러 방식이 생겼고
ES6에서 `class` 문법이 추가되었지만 이 문법도 내부적으로는 일정 부분 프로토타입을 활용합니다.

즉 자바스크립트의 클래스를 이해하려면 6장에서 배운 **프로토타입** 개념이 중요합니다.

## 클래스와 인스턴스의 개념 이해

---

## 클래스

클래스는 공통적인 특징을 가진 대상들을 묶은 **추상적인 개념**

```
음식
└─ 과일
   ├─ 배
   ├─ 사과
   ├─ 바나나
   ├─ 감
   └─ 오렌지
```

여기서 **음식**과 **과일**은 직접 만질 수 있는 실제 물건이 X

여러 대상을 공통 특징으로 묶은 분류

그래서 음식, 과일 같은 개념을 **클래스**라고 볼 수 있음

---

## 상위 클래스와 하위 클래스

## 내용 정리

클래스는 상하 관계를 가질 수 있음

예를 들어 **음식**은 **과일**보다 더 넓은 개념

그래서 음식은 과일의 **상위 클래스**이고, 과일은 음식의 **하위 클래스**

```
음식: 먹을 수 있음
과일: 먹을 수 있음 + 나무에서 열림
귤류: 먹을 수 있음 + 나무에서 열림 + 말랑한 껍질과 새콤달콤한 과육
```

```
음식
└─ 과일
   └─ 귤류
      ├─ 감귤
      ├─ 천혜향
      ├─ 자몽
      ├─ 오렌지
      └─ 레몬
```

## 인스턴스

## 내용 정리

인스턴스는 클래스에 속하는 **구체적인 실제 대상**

예를 들어 과일이라는 클래스가 있다면 사과, 바나나, 오렌지는 과일 클래스의 인스턴스라고 볼 수 있음

```
클래스: 과일
인스턴스: 사과, 바나나, 오렌지
```

| 구분 | 의미 | 예시 |
| --- | --- | --- |
| 클래스 | 공통 특징을 묶은 추상적인 개념 | 과일 |
| 인스턴스 | 클래스에 속하는 구체적인 대상 | 사과, 바나나, 오렌지 |

## 현실 세계와 프로그래밍에서의 차이

## 내용 정리

현실 세계에서는 이미 존재하는 대상을 보고 나중에 분류함

예를 들어 한 사람은 동시에 여러 분류에 속할 수 있는데 

```
나
├─ 남성
├─ 직장인
└─ 한국인
```

현실에서는 사람이 먼저 존재하고, 그 사람을 여러 기준으로 분류함

하지만 프로그래밍에서는 반대임

프로그래밍에서는 먼저 클래스를 정의하고 그 클래스를 바탕으로 인스턴스를 만듦

```
현실 세계:
실제 대상이 먼저 존재
→ 나중에 분류

프로그래밍:
클래스를 먼저 정의
→ 그 클래스로 인스턴스 생성
```

쉽게 말하면 

```
클래스 = 설계도
인스턴스 = 설계도로 만든 실제 결과물
```

# 자바스크립트의 클래스

## 내용 정리

자바스크립트는 원래 클래스 기반 언어가 아니라 **프로토타입 기반 언어**

하지만 프로토타입을 클래스 관점에서 보면 비슷하게 해석할 수 있는 부분이 있는데

예를 들어 `Array` 생성자 함수를 `new`와 함께 호출하면 배열 인스턴스가 생성됩니다.

```
vararr=newArray(1,2);
```

```
vararr= [1,2];
```

이 배열 인스턴스는 `Array.prototype`에 있는 메서드들을 사용할 수 있다.

```
arr.push(3);
arr.forEach(function (item) {
console.log(item);
});
```

정확히 말하면 상속이라기보다는 **프로토타입 체이닝을 통한 참조**

하지만 결과적으로 인스턴스가 메서드를 자기 것처럼 사용할 수 있기 때문에 클래스처럼 해석할 수 있다.

---

## 스태틱 멤버와 인스턴스 멤버

## 내용 정리

자바스크립트에서 생성자 함수와 prototype을 클래스처럼 보면, 메서드는 크게 두 종류로 나누는데.

```
1. 프로토타입 메서드
2. 스태틱 메서드
```

책에서는 인스턴스가 참조할 수 있는지에 따라 구분한다고 나왔음

---

## 프로토타입 메서드

## 내용 정리

프로토타입 메서드는 생성자 함수의 `prototype`에 정의된 메서드

이 메서드는 인스턴스가 직접 호출할 수 있다.

```
vararr= [1,2];

arr.push(3);
arr.forEach(function () {});
```

`push`, `forEach`, `map`, `filter` 같은 메서드는 `Array.prototype`에 있고

인스턴스인 `arr`이 직접 호출 가능

```
Array.prototype.push
Array.prototype.forEach
Array.prototype.map
Array.prototype.filter
```

이런 메서드를 **프로토타입 메서드**라고 함

---

## 스태틱 메서드

## 내용 정리

스태틱 메서드는 생성자 함수 자체에 직접 정의된 메서드

이 메서드는 인스턴스가 직접 호출  X

생성자 함수에서 직접 호출

```
vararr= [1,2];

Array.isArray(arr);// 가능
arr.isArray();// 불가능
```

| 구분 | 위치 | 호출 가능 대상 | 예시 |
| --- | --- | --- | --- |
| 프로토타입 메서드 | 생성자 함수.prototype | 인스턴스 | `arr.push()` |
| 스태틱 메서드 | 생성자 함수 자체 | 생성자 함수 | `Array.isArray(arr)` |

# Rectangle 예제

## 생성자 함수

```
var Rectangle=function (width,height) {
this.width=width;
this.height=height;
};
```

`Rectangle`은 가로와 세로를 받아서 사각형 인스턴스를 만드는 생성자 함수

```
varrect1=newRectangle(3,4);
```

이 코드를 실행하면 `rect1`이라는 인스턴스가 만들djwla

```
rect1.width = 3
rect1.height = 4
```

---

## 프로토타입 메서드: getArea

```
Rectangle.prototype.getArea=function () {
returnthis.width*this.height;
};
```

```
console.log(rect1.getArea());
// 12
```

이때 `this`는 `rect1`을 가리킴

```
this.width * this.height
= 3 * 4
= 12
```

따라서 `getArea`는 **프로토타입 메서드**

---

## 정리

1. 자바스크립트는 원래 프로토타입 기반 언어이다.

2. 클래스는 공통 속성을 묶은 추상적인 개념이다.

3. 인스턴스는 클래스에 속하는 구체적인 실제 대상이다.

4. 상위 클래스와 하위 클래스는 더 넓은 개념과 더 구체적인 개념의 관계이다.

5. 프로그래밍에서는 클래스를 먼저 정의하고 그 클래스로 인스턴스를 만든다.

6. 자바스크립트에서는 생성자 함수와 prototype을 이용해 클래스처럼 동작하게 만들 수 있다.

7. prototype에 정의된 메서드는 인스턴스가 직접 호출할 수 있는 프로토타입 메서드이다.

8. 생성자 함수 자체에 정의된 메서드는 생성자 함수가 직접 호출해야 하는 스태틱 메서드이다.
